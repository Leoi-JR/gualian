结构化关键词规则匹配引擎

基于自定义规则语法的大规模文本批量匹配工具集。 涵盖规则语法验证、模式编译转换、多阶段智能匹配与富文本结果导出，适用于需要对海量文本数据进行规则驱动分类标注的场景。

核心功能

四大模块，覆盖全流程

从规则编写到结果审查，每一步都有专用工具支撑

关键词规则验证器

读取 Excel 关键词文件，自动校验每条规则是否符合预定义的语法规范。支持 10 种组合模式（逻辑与、逻辑且、括号分组、正则距离限制等），自动识别中英文符号混用，生成带高亮标记的错误报告。

A&B 有序连接 A&&B 无序连接 括号分组 距离限制

关键词模式转换器

将人类可读的规则字符串编译为结构化匹配格式，供正则引擎直接消费。输出三种标准化表示：字符串直接匹配、有序位置匹配、无序位置匹配，每种格式携带间距约束参数。

[0] 字符串匹配 [1] 有序匹配 [2] 无序匹配 MD5 编译缓存

智能关键词匹配器

核心引擎。读取 Parquet 格式的大规模文本数据集，对每条记录执行三阶段短路求值：

1
Like 匹配
快速预筛选，检查候选关键词是否出现。失败则跳过后续阶段，减少 60–70% 无效正则计算。
2
Must 匹配
精确验证必须存在的关键词，支持有序 / 无序 / 距离限制三种模式。
3
Unlike 匹配
排除词过滤，若命中任意排除词则判定为不匹配。
Parquet 输入 多进程并行 可配置前置过滤

匹配结果高亮导出

将匹配结果导出为富文本 Excel 文件。命中项以绿色高亮标记，未命中项以红色标记，一目了然，便于人工复核审查。支持按时间区间筛选结果文件、批量处理。

CellRichText 批量处理 时间区间筛选

灵活配置管理

支持 JSON + .env 双配置模式，提供类型安全的配置接口。前置过滤条件、并发进程数、批处理策略阈值、字段范围控制均可独立调整，无需改动核心代码。

JSON 配置 .env 支持 Pydantic 验证

性能优势

为大规模数据而生

多项工程优化策略确保在海量文本数据下依然高效稳定

多进程并行

ProcessPoolExecutor 根据 CPU 核心数自动分配，文件级任务并行处理

自适应批处理

依据数据量动态切换策略：<5K 传统 / <50K 向量化 / ≥50K 分块向量化

编译结果缓存

MD5 哈希索引已编译正则，线程池并行预编译，避免重复开销

内置性能分析

PerformanceProfiler 记录各阶段耗时与内存增长，精准定位瓶颈
